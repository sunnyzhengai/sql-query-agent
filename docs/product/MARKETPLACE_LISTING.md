## Full Description

**The Problem**

Your organization has thousands of SQL files containing critical business logic — metric definitions, filter criteria, transformation rules. But this knowledge is locked in code that only a few developers can read. Business users wait weeks for answers. Data governance teams document 50 definitions per year while hundreds of new reports are created. Trust in data erodes.

**The Solution**

AIVIA automatically extracts business logic from your SQL files, builds a three-layer knowledge graph, and enables self-service analytics through a Microsoft Fabric Data Agent.

Ask questions like "How is this report calculated?" or "What filters does this metric apply?" and get instant, plain-English answers traced directly to the source SQL — no developer needed.

**How It Works**

1. Load your SQL files into Microsoft Fabric
2. AIVIA parses them using Microsoft's native ScriptDom parser (99%+ accuracy on enterprise T-SQL)
3. A certified knowledge graph is built in Delta tables: business metrics, calculation logic, and source tables
4. Users ask a Fabric Data Agent questions in natural language
5. The agent reads the graph and translates SQL logic into business language

**Key Features**

- 99%+ parse accuracy on real-world enterprise SQL (multi-statement queries, temp tables, CTEs, views)
- Three-layer knowledge graph: Business Metrics → Calculation Logic → Source Tables
- Plain-English answers for business users, full SQL details for developers
- Human-in-the-loop certification: stewards validate every definition
- Complete audit trail from question to source table
- Error classification with user-facing explanations

**Fabric-Native, BYOT**

AIVIA runs entirely within your Microsoft Fabric tenant. Delta tables, Fabric Data Agent, Spark notebooks — no external infrastructure. Your data never leaves your environment. No BAA required.

**Pricing**

$2,000/month — everything included. SQL parsing, knowledge graph, Data Agent, error reporting, pipeline validation, and automated sync to Collibra, Microsoft Purview, and Power BI. 30-day free trial. 10% discount on annual commitment.
