# ADR 0010: Skip Founders Hub Level 3, Go Direct to Partner Center

**Status:** Accepted
**Date:** 2026-07-25 (extracted from MARKETPLACE_PIVOT.md D3)

## Context

Founders Hub Level 3 approval requires a polished demo but grants only ~$25K in
Azure credits. Marketplace listing runs through Partner Center, which operates
independently of Founders Hub.

## Decision

Do not spend time polishing a demo for Level 3. Focus all effort on Partner
Center submission requirements.

## Consequences

- Level 3 does not unlock Marketplace access or Co-Sell status — no gating lost
- Forgoes the Azure credits (acceptable if self-funded)
- Every day not spent on Founders Hub is a day shipping toward market
